# Napper brand artwork

These files use the official app icon published by **Napper AB** for
[Napper: Baby Sleep Tracker on the App Store](https://apps.apple.com/us/app/napper-baby-sleep-tracker/id1491340863).
Retrieved on 2026-10-09 using Apple's public
[Lookup API](https://itunes.apple.com/lookup?id=1491340863).

Source image URLs:

- [256 px PNG](https://is1-ssl.mzstatic.com/image/thumb/Purple211/v4/16/07/d5/1607d54c-af24-f457-d44a-372c831fdbac/AppIcon-0-0-1x_U007emarketing-0-11-0-85-220.png/256x256bb.png)
- [512 px PNG](https://is1-ssl.mzstatic.com/image/thumb/Purple211/v4/16/07/d5/1607d54c-af24-f457-d44a-372c831fdbac/AppIcon-0-0-1x_U007emarketing-0-11-0-85-220.png/512x512bb.png)

The PNGs were downloaded at their target sizes without redrawing or recoloring.
`icon.png` and `logo.png` use the same square app artwork; their `@2x` variants
use the 512 px version. This preserves the existing file layout.

[Home Assistant 2026.3 and later](https://developers.home-assistant.io/blog/2026/02/24/brands-proxy-api/)
can display these local assets automatically. Older supported Home Assistant
versions do not gain local brand image support from this change.

The artwork identifies the Napper app. Napper's brand and artwork belong to
their respective owner; the repository's MIT license does not grant rights
to Napper's artwork. This independent integration is not affiliated with or
endorsed by Napper.
